🔥 Reglas de Seguridad para Firebase

Para permitir que la aplicación lea y escriba datos en tiempo real sin pedir inicio de sesión, debes pegar las siguientes reglas en la consola de Firebase:

  1. Entra a tu consola de Firebase: console.firebase.google.com
  2. Abre tu proyecto calidadextrusion-d9f60.
  3. En el menú lateral, ve a Firestore Database.
  4. Haz clic en la pestaña Reglas (Rules) en la parte superior.
  5. Reemplaza todo el texto que veas por el siguiente bloque de código:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

6. Haz clic en el botón azul Publicar (Publish).
